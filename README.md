# 환승로그

**기다리는 시간도, 여행이 되도록.**

인천공항 환승객이 가용시간과 취향에 맞춰 짧은 한국 여행을 만들고, 비·도착 지연·교통·현재 위치에 따라 일정을 다시 설계하는 반응형 웹 앱입니다.

## 실행

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. Windows에서는 `실행하기.cmd`를 실행해도 됩니다.

```sh
npm test
npm run build
```

`dist/`는 정적 호스팅 결과물입니다. 모든 화면, 계획 계산, 저장, 공유, 백업은 정적 호스팅에서도 동작합니다. 한국관광공사 API 프록시는 별도 서버 기능이므로 `server.mjs`가 동작하는 환경이 필요합니다. 정적 배포에서는 API 연결 버튼이 예시 정보 유지 상태를 안내합니다. 날씨는 브라우저에서 Open-Meteo에 직접 요청합니다.

| 화면 | 기능 |
|---|---|

| 장소 탐색 | 8개 장소, 카테고리·지역·실내 필터, 키워드 검색, 즐겨찾기, 상세 지도, 공식 안내와 길찾기 |
| 나의 환승 | 날짜·도착·출발·다음날·터미널·수하물·입국 확인·시간 여유·취향·예산·교통 입력 |
| 코스 추천 | 시간, 정기 휴관 예시, 예산, 입국 확인 조건을 통과한 최대 6개 코스 |
| 여행 일정 | 시간순 일정, 관광시간·비용·복귀 시각·추가 여유, 인쇄, 캘린더 내보내기, 기기 공유 |
| 상황별 재계획 | 비·눈·도착 지연·교통 지연·피곤함·현재 장소와 시각·남은 예산·장소 제외, 변경 전후 비교와 기록 |

| 경유편 비교 | ICN·SIN·HND 후보 최대 6개 직접 입력, 가격과 예상 관광 가능 시간 비교, 인천 코스 설계로 연결 |
| 여행 기록 | 일정·메모 저장, 제목·기록 편집, 즐겨찾기, JSON 백업·가져오기 |
| 환승 가이드 | 입국·수하물·교통·운영시간 체크리스트, 비자·K-ETA·환승관광·공항철도 공식 링크 |
| 공통 | 한국어·영어 전환, 모바일 하단 메뉴, 키보드 접근·모달 포커스, 브라우저 저장, 오프라인 셸 |

## 실제 데이터 연결

1. `.env.example`을 `.env`로 복사합니다.
2. 공공데이터포털에서 승인받은 한국관광공사 국문 관광정보 API 키를 `TOUR_API_KEY`에 설정합니다.
3. 서버를 재시작한 뒤 장소 탐색의 **관광정보 불러오기**를 누릅니다.
4. API 응답이 성공했을 때만 연결 상태가 표시됩니다.

키는 서버에서만 사용하고 브라우저에 전달하지 않습니다. 인코딩·디코딩 키 입력을 지원합니다. 검색 응답을 메모리에만 표시하며 관광공사 원본 데이터를 데이터베이스나 서비스 워커에 복제하지 않습니다. 키가 없거나 요청이 실패하면 예시 상태를 유지합니다. 키 설정 후 실제 승인·응답 확인은 별도로 필요합니다.

- 기본 URL: `https://apis.data.go.kr/B551011/KorService2`
- 장소 조회: `searchKeyword2` — 8개 큐레이션 장소명 기준 요청
- 서버 상세 엔드포인트: `/api/detail?id=CONTENT_ID` → `detailCommon2`
- 제공 정보: 관광공사 사진·주소·콘텐츠 ID·연결 상태
- 출처: ⓒ한국관광공사

## 계산 범위와 한계

이 앱은 항공권 예약 서비스나 입국 자격 판정 서비스가 아닙니다. 항공편 비교는 사용자가 입력한 수치로 계산합니다. 기본 장소의 운영시간·입장 비용·대중교통 및 택시 이동시간은 **시연을 위한 고정 추정값**입니다. 현재 실시간 교통, 항공편 상태, 임시 휴관, 공휴일 예외, 잔여 티켓 수를 조회하지 않습니다. API 사진·주소 연결이 시간·요금의 정확성까지 보장하지 않습니다.

전체 환승시간에서 입국 준비, 수하물 추가시간, 도착 지연, 출국 전 준비, 추가 여유, 터미널 추가 여유를 뺍니다. 후보별 왕복 이동·관람·개장 대기를 계산하고 예산·복귀 기준·정기 휴관·날씨 조건으로 필터링합니다. 같은 지역에서 최대 2개 장소를 묶어 취향 점수로 정렬합니다. 비와 눈을 선택하면 야외 장소를 제외합니다. 외부에서 재계획할 때는 현재 시각·장소와 남은 예산을 기준으로 같은 지역을 탐색합니다.

복귀 알림은 페이지가 열려 있을 때만 확인하는 화면 알림이며 백그라운드 푸시가 아닙니다. 캘린더 파일에는 복귀 출발 15분 전 알림이 포함되며 실제 알림 처리는 가져온 캘린더 앱에 따릅니다. 입국·탑승·복귀 시각을 보장하지 않습니다.

날씨는 선택한 날짜의 인천 예보를 Open-Meteo에서 요청합니다. 예보 범위 밖 날짜나 연결 실패를 별도로 안내합니다. 주변 모든 지역의 실황을 대표하지 않습니다.

## 파일 구조

- `public/`: 화면, 디자인, 데이터, 계획 엔진, 이미지
- `server.mjs`: 정적 파일 서버와 관광 API 프록시
- `tests/`: 시간·날씨·휴관·예산·현재 위치·서버 경계 검증
- `scripts/build.mjs`: 정적 배포 파일 생성
- `.env.example`: 인증키 설정 예시
- `.openai/hosting.json`: 비공개 웹 배포 프로젝트 설정
- `FEATURES.md`: 공모전 기능 설명과 시연 흐름
- `public/assets/credits.json`: 사진별 저작자·출처·라이선스

## 디자인과 이미지

크림색 종이, 짙은 청록, 코럴을 바탕으로 여행 매거진의 큰 타이포그래피와 항공 탑승권의 정보를 조합했습니다. 데스크톱은 여백과 사진 중심, 모바일은 한 열과 하단 탐색 메뉴를 사용합니다.

브랜드 이미지 `public/assets/hero.png`는 내장 ImageGen으로 생성했습니다. 서울에서의 실제 비행 경로나 전망을 표현한 사진이 아닙니다. 사용 프롬프트 요약:

> Premium editorial travel website hero, wide 3:2. Oval airplane window with creamy ivory cabin on the left, Korean coastal mountains, Seoul-inspired skyline and Han River at sunrise, wing in the lower foreground. Pale apricot and coral sky, teal-blue landscape, soft analog grain, Kinfolk travel magazine atmosphere. No people, no text, no logos, no UI. Evocative, not geographically precise.

영종도 지역 스케치는 자체 SVG 일러스트이며 길찾기 지도가 아닙니다. 외부 사진은 `credits.json`의 개별 라이선스를 따릅니다. CC BY-SA 사진의 파생 표시도 원래 라이선스로 제공합니다. 지도는 © OpenStreetMap contributors, 아이콘은 Lucide ISC, 서체는 SIL Open Font License입니다.

## 검증

14개 핵심 자동 검증: 자정 경계, 잘못된 날짜, 시간 여유, 입국 미확인, 비용·복귀 조건, 비·눈의 실내 제한, 정기 휴관, 짧은 시간, 현재 위치·예산, 장소 제외, 경유편 유효성, 인증키 없음, 관광 메타데이터 변환, 서버 경로 제한.

브라우저에서 데스크톱과 모바일 화면, 일정 생성, 날씨 변경 전후 비교·적용, 메모·일정 저장과 새로고침 유지, 입국 확인 분기, 장소 검색·지도, 영어 화면, 경유편 비교를 확인했습니다. 실제 관광공사 인증키와 실항공편 예약은 연결·검증하지 않았습니다.
